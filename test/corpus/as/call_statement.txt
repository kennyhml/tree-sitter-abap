[ ABAP - Application Server / System Function Call ] Basic form
=================================================================================
CALL 'C_SAPGPARAM'.
---

(source
  (call_statement
    name: (string_literal)))

=================================================================================
[ ABAP - Application Server / System Function Call ] Dynamic function
=================================================================================
CALL system_function.
---

(source
  (call_statement
    name: (identifier)))

=================================================================================
[ ABAP - Application Server / System Function Call ] Parameter
=================================================================================
CALL 'C_SAPGPARAM' ID 'NAME' FIELD name.
---

(source
  (call_statement
    name: (string_literal)
    (id_field_spec
      id: (string_literal)
      field: (identifier))))

[ ABAP - Application Server / System Function Call ] Multiple parameters

  (call_statement
    name: (string_literal)
    (id_field_spec
      id: (string_literal)
      field: (string_literal))
    (id_field_spec
      id: (string_literal)
      field: (identifier))))
