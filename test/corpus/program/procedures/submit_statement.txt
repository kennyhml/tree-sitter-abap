=================================================================================
[ ABAP - Calling and Exiting Program Units / Calling Programs / SUBMIT ] Selection screen options
=================================================================================
SUBMIT report
  USING SELECTION-SCREEN '1100'
  VIA SELECTION-SCREEN
  USING SELECTION-SET variant
  USING SELECTION-SETS OF PROGRAM program
  WITH SELECTION-TABLE selections
  WITH parameter EQ value SIGN sign
  WITH FREE SELECTIONS free_selections
  AND RETURN.
---

(source
  (submit_statement
    report: (identifier)
    (using_selection_screen_spec
      number: (string_literal))
    (via_selection_screen)
    (using_selection_set_spec
      name: (identifier))
    (using_selection_sets_of_program_spec
      program: (identifier))
    (with_selection_table_spec
      table: (identifier))
    (with_selection_criteria_spec
      expression: (comparison_expression
        left: (identifier)
        right: (identifier))
      (sign_spec
        sign: (identifier)))
    (with_free_selections_spec
      selections: (identifier))
    (and_return)))
